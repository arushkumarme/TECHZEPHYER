# M1 Protocol Models Implementation Plan

> Executed natively. **Spec:** `docs/05-protocol-spec.md` §2–§5, §7; `docs/03-agents.md` §3; `docs/08` §3.1 (cause types).

**Goal:** Typed, versioned, validated message envelope and payloads for all eight message types, with "unknown fields ignored and logged", "missing required fields rejected", semantic version rules, and committed JSON Schemas.

**Architecture:** Pydantic v2 models in `src/netcoop/core/`. Payload models forbid nothing silently: `parse_message()` validates with `extra="ignore"` models but first diffs raw keys against model fields to report ignored fields. Version policy in one function. IDs and clock injectable for deterministic replay.

## Global Constraints
- Agent identifiers fixed: `orchestrator`, `performance_agent`, `infrastructure_agent`, `connectivity_agent`, `correlation_agent`, `reporting_agent`, `community_module`.
- `PROTOCOL_VERSION = "1.0"`; every payload type at `"1.0"`.
- `sent_at` must be timezone-aware UTC.
- Error code on invalid message: `MESSAGE_INVALID`; on unsupported major version: `PROTOCOL_VERSION_UNSUPPORTED`.

## Review Focus
- Message whose `message_type` and payload shape disagree (e.g. a `finding` carrying a task payload) → rejected.
- Naive timestamp → rejected.
- Response (`finding`, `clarification_response`, `report_ready`, `decision`) without `in_reply_to` → rejected.
- Minor-version bump (`1.3`) with an extra field → accepted, extra field reported as ignored.
- Severity outside the closed list → rejected.

### Task 1: vocabulary + building blocks (`core/vocab.py`, `core/blocks.py`)
Produces: `AgentId`, `MessageType`, `CauseType`, `Severity`, `Assessability`, `NotAssessableReason`, `QuestionType`, `ClarificationReason`, `DecisionKind`, `TrustLabel` (Literals); models `TimeWindow`, `Observation`, `Hypothesis`, `NotAssessableItem`, `Limitation`, `ToolCallRecord`, `SelfAssessment`, `ScoredHypothesis`, `ConflictRecord`.

### Task 2: envelope, payloads, parse/serialize (`core/messages.py`)
Produces: `Envelope`, payload classes `TaskRequest, Finding, ClarificationRequest, ClarificationResponse, Decision, ReportReady, AgentError, CommunityCandidate`; `PAYLOAD_TYPES: dict[MessageType, type[BaseModel]]`; `make_message(...) -> Envelope`; `parse_message(raw: str | bytes | dict) -> ParsedMessage(envelope, payload, ignored_fields)`; `MessageValidationError(code, detail)`; `Envelope.to_json() -> str`.
Tests (T-PROTO-01..10): round trip for every type; missing required envelope field; missing required payload field; unknown fields ignored+reported at both levels; type/payload mismatch; naive datetime; response without `in_reply_to`; major version 2.x rejected, 1.7 accepted; invalid sender; severity enum.

### Task 3: ids/clock + JSON Schema export (`core/ids.py`, `core/schema_export.py`, `schemas/*.json`)
Produces: `IdFactory(prefix_seq)` with `.incident() -> "INC-0001"`, `.message() -> "MSG-000001"`, `.next(kind)`; `Clock` protocol + `SystemClock`, `FixedClock(start, step)`; `export_schemas(out_dir) -> list[Path]`.
Tests: contract test that committed `schemas/` equal fresh export (T-PROTO-SCHEMA-01); ids are sequential and deterministic.
